# 🎯 Laksh.ai – Career Guidance Platform

**Laksh.ai** is an AI-powered career guidance platform created to support students in India’s **tier-2 and tier-3 cities**. It helps users identify their strengths, explore career options, build professional resumes, and plan their learning journey — all through smart automation, quizzes, and integrations with tools like **Google Vertex AI** and the **YouTube Data API**.

---

## 🌟 Features

- **📄 Resume Skill Extraction**  
  Upload your resume and let the system automatically extract your skills using AI-powered text analysis.

- **📝 Resume Builder**  
  Build a clean, professional resume using a form-based tool. Perfect for first-time job seekers or students.

- **📹 YouTube Video Recommendations**  
  Curated videos based on career roles and interests using the **YouTube Data API**.

- **🧠 Career Quiz**  
  Personalized quiz to assess your interests and suggest career fields based on your strengths.

- **💼 Skill-to-Job Mapping**  
  Matches your identified skills to potential career roles — helps you discover jobs that fit your current capabilities.

- **🧭 Personalized Roadmaps**  
  Visual learning plans for various career paths including certifications, skills, and tools to acquire.

---

## 🛠️ Technologies Used

- **Frontend:** HTML5, CSS3, JavaScript (for forms and interactivity)
- **Backend:** Python with Flask
- **AI/ML Integration:** Google Vertex AI (for NLP, skill extraction)
- **APIs:**
  - YouTube Data API (for video recommendations)
  - Firebase (optional - for storing quiz results, resumes, and user auth)
- **Data Handling:** JSON, Pandas, NLTK (for data parsing and natural language processing)
